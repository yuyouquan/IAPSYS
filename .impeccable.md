## Design Context

### Users
Enterprise operations and management staff handling independent app publication workflows. They work in fast-paced environments managing multi-step approval processes across channels, materials, and releases. The job: efficiently move applications through a 7-stage pipeline with clarity at every step.

### Brand Personality
**Refined. Technical. Efficient.**
The interface should feel like a premium control center — precise, polished, and purposeful. Every pixel should communicate competence and sophistication.

### Aesthetic Direction
- **Visual Tone:** Elevated tech glassmorphism — not subtle glass, but confident and distinctive. Surfaces should feel layered with depth. Gradients should be intentional and striking. Micro-interactions should feel premium.
- **Theme:** Light mode with rich contrast. Cool blues and cyans as primary, with strategic warm accents for visual interest.
- **Anti-references:** Plain/flat enterprise dashboards, generic Ant Design defaults, sterile corporate UIs with no personality.
- **Goal:** Transform from "functional but plain" to "refined and impressive" — the kind of interface that makes users feel they're using a premium product.

### Design Principles

1. **Depth Over Flatness** — Use layered glass, gradients, and shadows to create visual depth. Every surface should feel like it exists in 3D space.
2. **Strategic Contrast** — Important elements should pop. Use color, scale, and glow to create clear focal points. Nothing should feel monotonous.
3. **Precision Details** — Micro-details matter: subtle border gradients, refined shadows, icon treatments, badge designs. Polish is what separates good from great.
4. **Motion With Purpose** — Animations should feel responsive and premium — spring physics, smooth reveals, hover states that reward interaction.
5. **Data Clarity** — Despite visual richness, data readability is paramount. Typography hierarchy, spacing, and color coding must serve efficiency first.
